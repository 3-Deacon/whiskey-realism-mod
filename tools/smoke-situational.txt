# Situational patch ids for tools/smoke-check.py.
#
# The reference smoke session is: launch GTCW, start or load a campaign, let the
# campaign AI run for some in-game days, then fight one battle on the tactical
# map with AI-controlled formations on both sides. Every patch id NOT listed
# here must log a "[first-fire] <id>" line in that session; smoke-check exits 1
# otherwise.
#
# An entry is "<id-or-glob>  # reason". A trailing * matches any suffix. Each
# reason names the vanilla call path that a normal session may not reach.
