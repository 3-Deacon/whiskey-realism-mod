# Vanilla Campaign Logistics Bugs

Campaign AI supply, depot, deployment and tempo bugs confirmed on Steam build 14703111 (2026-10-15). Source research: the deploy/supply investigation (ranked findings #2, #3, #5, #6, #7, #11). The two Transpilers (`BUG-LOG-010`, `BUG-LOG-011`) were approved by the user 2026-10-15: "Approve both (Recommended)". Every anchor below was re-read in `/tmp/gt_src/asm/Assembly-CSharp.decompiled.cs`; `cp:n` is a line of `<GTCW>/Config/campaignprefs.txt`. Plan and smoke items: [`../superpowers/plans/2026-10-15-campaign-logistics-bugs.md`](../superpowers/plans/2026-10-15-campaign-logistics-bugs.md).

Patch ordinals #81-#91 (#80 is BC9's). Each item was either **fixed** to vanilla's evident intent (config text, tooltips, the manual, or the surrounding code), or **recorded** with the evidence and left as vanilla where the intent is genuinely ambiguous. Fixes apply to every faction alike; none moves the W&L player's own command (vanilla's own move guards stay in place, and the raid fix skips player-commanded raid groups). All fix flags live in section `Campaign Bug Fixes` and default on. Every save, write and restore the patches make runs on stand-ins in the harness (`Patches/LogisticsSwaps.cs`), and the runtime wiring is pinned in the patch sources (`CampaignLogisticsGlueTests`).
